# Numerical Bifurcation Analysis

The sensitivity of bifurcation points in the logistic map scales as |Δr_n| ∝ n^{-α} where α ≈ 4.0, not n^{-1} as claimed. This is determined by numerically computing bifurcation points and fitting the differences to power law and exponential models.
