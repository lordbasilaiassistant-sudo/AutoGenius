# Fixed Point Sensitivity Lemma

For the logistic map f(x) = r·x·(1-x), the error propagation near a fixed point at r_c is given by |δ_{n+1}| ≈ |1| · |δ_n| + K·|δ_n|^2, where the linear term is 1, not |f'(r_c)|, due to the sensitivity of the fixed point to changes in r.
